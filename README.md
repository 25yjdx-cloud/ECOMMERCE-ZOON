# CommerceForge

CommerceForge هو مصنع متاجر إلكترونية مستقلّة يهدف إلى تسريع تسليم المتاجر للعملاء، مع عزل بيانات كل عميل وإتاحة واجهة موحّدة قابلة للتخصيص حسب القطاع والسوق.

## الرؤية

- **Backend:** نسخة مستقلة من Bagisto/Laravel وقاعدة بيانات خاصة لكل عميل.
- **Storefront:** واجهة Next.js موحّدة بنظام قوالب مرن؛ البداية بالقالب `theme-1-lifestyle`.
- **Business dashboard:** مساحة مالية سرية لمتابعة الأرباح والخسائر وتكلفة المنتجات.
- **الأسواق:** مصر والخليج مع دعم RTL والعملات ووسائل الدفع المحلية، مع قابلية التوسع لاحقاً إلى أستراليا.

## الحالة الحالية

المشروع في **Phase 0 — تأسيس الهيكل والتوثيق**. المجلدات والملفات الحالية هي نقاط بداية توثيقية؛ لا تتضمن منطقاً تطبيقياً أو كوداً تشغيلياً.
