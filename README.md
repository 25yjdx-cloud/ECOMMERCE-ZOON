# CommerceForge

CommerceForge هو مصنع متاجر إلكترونية مستقلّة يهدف إلى تسريع تسليم المتاجر للعملاء، مع عزل بيانات كل عميل وإتاحة واجهة موحّدة قابلة للتخصيص حسب القطاع والسوق.

## الرؤية

- **CommerceForge Core:** مصدر كود مشترك تتم صيانته وإعادة استخدامه.
- **Backend:** Laravel وBagisto؛ يحصل كل عميل على نشر مستقل وقاعدة بيانات وإعدادات وأسرار منفصلة.
- **Storefront:** Next.js وReact وTypeScript مع خمسة قوالب رسمية مسجلة في `config/templates/presets.json`؛ القوالب كلها مخطط لها ولم تُنفذ بعد.
- **لوحة العميل:** لوحة Next.js/React مخصصة لإدارة متجر العميل وتقاريره؛ لوحة CommerceForge الداخلية مؤجلة.
- **Meta Ads:** تكامل منفصل لكل عميل وأولوية مرتفعة بعد تأسيس الاتصالات الآمنة.
- **اللغات والأسواق:** دعم العربية RTL والإنجليزية LTR، مع ضبط العملة واللغة لكل متجر.

CommerceForge ليس منصة SaaS متعددة المستأجرين؛ لا تشترك متاجر العملاء في قواعد البيانات أو بيانات الاعتماد.

## الحالة الحالية

المشروع في **Phase 0 — التدقيق والتأسيس**. أُعدت وثيقة الاستراتيجية وسجل القوالب، لكن لا توجد تطبيقات أو وظائف متجر تشغيلية، ولم يُثبت Laravel أو Bagisto.
