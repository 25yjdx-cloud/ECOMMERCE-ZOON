# Backend لكل عميل

سيحتوي هذا المسار مستقبلاً على توثيق وإعدادات التكامل مع **تثبيت مستقل من Bagisto/Laravel لكل عميل**، مع **قاعدة بيانات MySQL مستقلة** لذلك العميل.

لا يُنشأ هنا مشروع Laravel تجريبي أو تثبيت Bagisto. بيانات الاعتماد وإعدادات الاتصال يجب أن تبقى خاصة ببيئة العميل، وألا تُشارك بين المتاجر.

**الحالة:** مخطط فقط؛ لا يوجد Backend أو اتصال API منفّذ.
