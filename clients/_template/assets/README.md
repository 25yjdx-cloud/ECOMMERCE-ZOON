# assets

Put the client's files here:
- `logo.svg` (or `.png`) and optionally `logo-dark.svg`
- `favicon.png`
- `og.png` (share image, 1200 x 630)
- `banners/` (home page banners)

Use only files the client owns or has licensed. The prepare-client tool (Phase 3) copies them into `storefront/public/client-assets/SLUG/`.
