# الوثيقة الهندسية الرئيسية

## الهدف

CommerceForge منصة لإنتاج متاجر إلكترونية مستقلة للعملاء. لكل عميل Backend وقاعدة بيانات منفصلان، بينما تُستخدم واجهة Storefront موحّدة ونظام قوالب قابل للتهيئة.

## المبادئ

- عزل بيانات العملاء وأسرارهم.
- توحيد تجربة الواجهة مع تخصيص القالب عبر الإعدادات.
- مراعاة RTL والأسواق والعملات المحلية.
- حماية Business Dashboard والبيانات المالية.
- مراجعة واعتماد القرارات قبل التنفيذ.

## النطاق الحالي

Phase 0: هيكل الملفات والوثائق التأسيسية فقط. لا يوجد تنفيذ تشغيلي معتمد.

تُستكمل هذه الوثيقة بعد اعتماد المعمارية ومصفوفة التقنيات ونطاق المنتج.
