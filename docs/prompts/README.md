# docs/prompts

Ready prompts for AI agents. Each prompt is self-contained and states its scope.

- `00-skeleton-kickoff.md` - tells an agent to verify the folder skeleton only. No code, no installs.
- `01-reviewer.md` - tells a second agent to review the specification and the structure. No rewriting.

Later phases get their own prompt files here. Existing prompt files are never deleted (AGENTS.md rule 0.1).
