# Storefront

تطبيق واجهة واحد مستهدف بـ Next.js App Router وReact وTypeScript وTailwind CSS، يخدم متاجر مستقلة عبر إعدادات العلامة التجارية والسوق واختيار القالب.

## حدود المسؤوليات

- `src/app/`: مسارات Next.js وتجميع واجهة التطبيق.
- `src/components/`: مكونات مشتركة مستقلة عن القالب.
- `src/themes/`: عروض ومكونات وأقسام خاصة بالقوالب، ومنها Theme 1.
- `src/theme-engine/`: نقاط توثيقية لتسجيل القوالب واختيارها وربطها.
- `src/config/`: إعدادات المتجر والمنطقة واللغة والعملة والعلامة التجارية.
- `src/services/`: نقطة تنظيم مستقبلية للاتصال بـ Bagisto APIs؛ لا تحتوي حالياً على API منفّذ.
- `src/types/` و`src/lib/`: تعريفات مشتركة ومساعدات مستقبلية.

يجب فصل مكونات العرض عن الاتصال بالخدمات، وعدم تضمين بيانات منتجات وهمية أو أسرار عملاء. لا يغيّر اختيار القطاع أو القالب بيانات Backend.

**الحالة:** هيكل تأسيسي فقط؛ لا توجد وظائف متجر منفّذة أو مختبرة.
