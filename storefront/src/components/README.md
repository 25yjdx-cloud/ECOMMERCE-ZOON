# src/components

Generic UI blocks with no commerce logic and no preset identity: `ui/` (button, input, modal, tabs, badge, skeleton), `forms/` (field wrappers), `feedback/` (alert, toast, empty and error states), `seo/` (metadata and structured-data helpers).

Share a component only when its behavior and implementation are truly common. Use logical CSS properties (ms-, me-, ps-, pe-, text-start) so RTL works.
