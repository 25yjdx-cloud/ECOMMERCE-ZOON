# src/gallery - gallery mode only

Components and content for the owner's sales gallery.

- `components/` - PresetCard, PresetGrid, GalleryHero, HowItWorks, ContactCta.
- `content/presets.json` - the preset list: ids, Arabic and English names, industries, status, whether the preset is featured on the home page, and its thumbnail path.
- `content/texts.ar.json` and `content/texts.en.json` - page texts (planned).

The gallery uses only mock data and never needs a backend.
